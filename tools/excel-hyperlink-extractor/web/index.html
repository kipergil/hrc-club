Cell Link Extractor

Spreadsheets hide their URLs behind the text you see. Drop a workbook in, pick an id column and the columns holding links, and read out every target as plain text. The file is read in this browser and never uploaded.

Reads .xlsx and .xlsm; re-save a legacy .xls from Excel first. Columns are matched by header where there is one, and by letter where there isn't. TSV and CSV give one line per link — row, id, column, cell, text, link, source — to paste back into a spreadsheet.
